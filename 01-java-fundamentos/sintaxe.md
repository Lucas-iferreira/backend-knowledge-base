# Sintaxe Java

## O que é?

Em Java, cada linha de código executada deve estar dentro de um bloco `class`. O nome da classe deve sempre começar com uma letra maiúscula `Main`.O nome do arquivo Java deve corresponder ao nome da classe.

---

## Como funciona?

O `main()` método é necessário em todos os programas Java. É nele que o programa começa a ser executado:

```java
public static void main(String[] args{}
```
cada instrução `java` é necessário terminar com `;`.

---

## Estrutura de um programa Java

```java
public class Main {

    public static void main(String[] args) {

        System.out.println("Olá Mundo");

    }

}
```
