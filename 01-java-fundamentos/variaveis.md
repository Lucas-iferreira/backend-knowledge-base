# Variaveis Java

## O que é?

São espaços de armazenamento na memória usados para  guardar dados. 

---

## Como funciona?

Podem ser do tipo:
- Referencia: Armazenam referencias a valores complexos como a classe para texto: `String`;
- Primitivos: Eles são predefinidos pelo sistema => `int`,`long`,`boolean`.

---

## Estrutura variáveis

```java
int n = 5; //int tipo primitivo
Carro meuCarro = new Carro(); //Carro, tipo referencia de um objeto. 

```
