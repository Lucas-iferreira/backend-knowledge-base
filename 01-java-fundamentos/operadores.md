# Variaveis Java

## O que é?

Os operadores em Java são símbolos especiais usados para executar operações em variáveis e valores.

---

## Tipos de operadores

1. Operadores Aritméticos: Usados para realizar contas matemáticas básicas.
- +. - (Adição / Concatenar texto)
- -. - (Subtração)
- *. - (Multiplicação)
- /  - (Divisão)
- %  - (Módulo - Resto da divisão)

2. Operadores Unários: Aplicados a apenas uma variável para alterar seu valor ou sinal.
- ++ - (Incremento - Aumenta 1)
- -- - (Decremento - Diminui 1)
- +. - (Sinal positivo)
- -. - (Sinal negativo / Inverte o sinal)! (Negação lógica - Inverte um booleano)

3. Operadores de Atribuição: Usados para definir ou atualizar o valor de uma variável.
- =  - (Atribuição simples)
- += - (Soma e atribui: x += y é o mesmo que x = x + y)
- -= - (Subtrai e atribui)*= (Multiplica e atribui)
- /= - (Divide e atribui)
- %= - (Calcula o resto e atribui)

4. Operadores Relacionais (Comparação): Sempre retornam um valor booleano (true ou false).
- == - (Igual a)
- != - (Diferente de)
- .> - (Maior que)
- <  - (Menor que)
- .>= - (Maior ou igual a)
- <= - (Menor ou igual a)

5. Operadores Lógicos: Usados para combinar múltiplas condições booleanas.
- && (E lógico / AND - Retorna true se ambas as condições forem verdadeiras)
- || (OU lógico / OR - Retorna true se pelo menos uma condição for verdadeira)
- ! (NÃO lógico / NOT - Inverte o resultado)

6. Operador Ternário: Uma forma compacta de escrever um comando if-else em uma única linha.
- ? : (Sintaxe: condicao ? valor_se_true : valor_se_false;)
